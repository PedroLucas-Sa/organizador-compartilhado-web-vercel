# Projeto — Estudo de Inglês

## Objetivo

Usar o ChatGPT para aprender inglês a partir de contextos reais, textos e necessidades específicas de escrita.

## Forma de interação

O padrão desejado é:

1. fornecer um contexto;
2. receber ajuda com esse contexto;
3. encerrar o contexto;
4. iniciar um novo contexto independente.

## Exemplo de uso

Foi trabalhada a elaboração de um prompt em inglês para pesquisa bibliográfica sobre nanopartículas de sílica.

O objetivo era pedir ajuda na busca por artigos relacionados a:

- silica nanoparticles;
- síntese pelo método de Stöber;
- estruturas core-shell;
- liberação gradual de nitrogênio.

## Filosofia de estudo

A correção deve priorizar:

- naturalidade;
- precisão de vocabulário;
- estrutura das frases;
- adequação ao contexto;
- diferenças entre linguagem cotidiana e científica.

## Questões em aberto

- Criar registro de erros recorrentes.
- Separar inglês acadêmico de inglês geral.
- Desenvolver exercícios de produção própria.
- Guardar vocabulário científico útil.
