## Como usar na conta nova

A recomendação é criar um Projeto no ChatGPT para cada área de trabalho de longo prazo e adicionar o `.md` correspondente como arquivo de contexto.

Os arquivos são uma consolidação, não uma cópia literal de todas as conversas. Quando uma informação não estava disponível no histórico resumido, ela foi deixada como questão em aberto ou não foi inventada.

## Estrutura sugerida

```text
Projeto/
├── contexto.md
├── decisoes.md
├── progresso.md
├── proximos-passos.md
└── referencias.md
```

Neste primeiro pacote, cada projeto foi consolidado em um único `contexto` para facilitar a migração. Depois, as áreas que crescerem podem ser separadas nos arquivos acima.
